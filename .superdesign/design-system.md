# Lemon Schedule UI

Mobile-first Korean social todo for close friends and family. Existing app shell: current atlas lemon logo + 레몬스케줄 wordmark, bell at top; four bottom links 할 일 / 친구 / 펫 / 내 정보. Use current shared source for exact icons. Primary content max-width 800px. Existing warm off-white #fafaf8, white #ffffff, ink #242720, muted #60665d, border #e4e6de; yellow #f9db69/#fff6bf, leaf green #397a4b/#f2f8f0. System sans/Pretendard stack. Body and inputs at least 16px, headings 24-28px. 8/12/16/24px spacing, 12-20px card radii, minimal shadow. 44-48px tap targets. No gradients, decorative fonts, purple/pink colors, emoji substitutes or oversized marketing banners.
New friends timeline: two primary views 타임라인 and 친구별. An interleaved chronological social feed of task registration and first completion; calm, encouraging, no rankings, likes, comments, online presence, or new notification counts. Only current approved friends. Repeating task generation is not registration. Recompletion is not a new activity. Cards use actual avatar art and explicit event verbs, readable task titles, event timestamps, small task date, and friend-day encouragement entry. Daily encouragement belongs to the recipient's day, NOT a per-event like; one per recipient per day. Existing friends view remains reachable. Selecting rounded tabs uses full background and font weight, not one-sided border.
