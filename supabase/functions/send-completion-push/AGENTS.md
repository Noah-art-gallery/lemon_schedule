# 완료 휴대폰 알림 발송

앱 안 `task_completed` 알림 INSERT 웹훅만 처리한다. 완료 상태·포인트·앱 안 알림 생성은 이 함수가 소유하지 않으며 브라우저에서 이 함수를 직접 호출하지 않는다.

32자 이상 비밀 헤더를 확인한 뒤 전달된 알림 ID를 서버 권한으로 다시 조회한다. 현재 연결·차단·완료·삭제 상태를 확인하기 전에는 기기 토큰을 읽거나 외부 발송을 시도하지 않는다. 기기별 `push_delivery_attempts` 선점에 성공한 요청만 발송하며, 실패는 시도 행에 기록하고 완료를 되돌리지 않는다.

FCM·APNs 키와 Supabase 서버 키는 Edge Function 비밀값으로만 사용한다. 오류 로그에 기기 토큰, 비밀키, 웹훅 헤더를 남기지 않는다. 비밀 헤더 거부·잘못된 이벤트·중복 선점·전송 실패를 검사하고, 실제 기기 검사는 Firebase/APNs 자격이 있는 환경에서 별도로 수행한다.
