# 직접 소식 휴대폰 발송

알림 INSERT 웹훅 중 받은 응원·연결 요청·연결 수락만 처리한다. task_completed는 건너뛰며 완료·보상·알림 생성 트랜잭션을 변경하지 않는다. 기존 함수 이름은 배포 호환성 때문에 유지한다.

32자 이상 비밀 헤더를 확인한 뒤 알림 ID를 서버 권한으로 다시 조회한다. 현재 수신자·연결·완료 상태·요청 상태·응원 가시성을 확인하기 전 기기 토큰을 읽거나 발송하지 않는다. 잠금 화면에는 할 일 제목과 응원 원문을 넣지 않는다. 탭 대상은 정확한 발생 건·응원·요청 ID로 구성한다.

기기별 발송 시도 선점에 성공한 요청만 보낸다. 외부 전송 실패는 기존 사용자 행동을 되돌리지 않는다. FCM·APNs·Supabase 서버 키는 서버 비밀값으로만 사용하고 토큰·헤더·키를 로그에 남기지 않는다. 단위 검사와 실제 기기 수신 검증을 구분한다.
