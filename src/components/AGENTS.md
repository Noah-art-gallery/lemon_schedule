# 공통 UI 모듈

앱 셸·내비게이션·소식 진입점과 공통 입력·버튼·패널을 소유한다. 소식 배지는 직접 소식 미읽음 조회를 사용하고 친구 완료 수를 더하지 않는다.

패널은 모바일에서 내용 높이에 맞춰 최대 94dvh까지, 데스크톱에서는 최대 520px 측면 배치로 표시한다. 데스크톱 본문 폭은 최대 800px이다. 배경 입력 차단·가시 요소만 초점 순환·Escape·뒤로가기·닫기 후 유효한 진입점 복귀를 유지한다. 파괴적 확인창은 취소에 첫 초점을 둔다. 버튼 문구는 잘리지 않게 배치하고 긴 조회 문구는 줄바꿈한다. 둥근 선택 버튼에 한쪽 테두리만 강조하는 스타일을 결합하지 않는다. 터치 영역은 44px 이상, 주요 행동은 48px 이상, 본문·입력 글자는 16px 이상으로 유지하고 좁은 화면과 긴 문구를 실제로 확인한다.
