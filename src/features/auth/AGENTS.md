# 인증 모듈

이 모듈은 카카오 웹 OAuth 시작, 로그아웃과 세션 상태를 소유한다. 이메일 가입·로그인 서비스와 입력 화면은 제공하지 않는다. 프로필 데이터 저장이나 친구 권한 판정은 담당하지 않는다.

카카오는 현재 origin의 정적 `/login/`으로 복귀하고 URL 세션 복원 뒤 앱으로 이동한다. 초대 코드와 기존 계정 보호·푸시 해제를 유지한다. `scopes`는 Supabase 기본 이메일·사진 권한을 덧붙이므로 `queryParams.scope`로 닉네임만 지정한다. 이메일 없는 가입을 지원하며 카카오 Client Secret은 Supabase 설정에만 둔다. 신규 카카오 프로필은 닉네임 또는 `레몬 친구`, `Asia/Seoul`로 시작한다. 기존 이메일 계정과 자동 병합하지 않으며 Capacitor 딥링크는 미구현이다.

처음 로그인하면 카카오 가입이 함께 처리되며 별도 회원가입 화면은 없다. 기존 `/signup` 주소는 초대 코드를 유지해 `/login/`으로 보낸다. 새 초대 링크는 `/login/?invite=...`를 사용한다. 카카오에서 받은 이름 또는 기본 이름·서울 시간대를 프로필 트리거가 초기화하고 이후 내 정보에서 수정한다. 인증 오류는 `AppError`로 변환한다.

테스트는 데모 플래그, 설정 누락, 세션 복원, 이메일 폼 부재, 예전 가입 주소·초대 코드 유지, 중복 요청·푸시 해제 실패를 포함해야 한다. 보호 화면은 `AuthProvider`의 상태 전환으로만 판단한다. 운영 Email provider 비활성화는 카카오 화면 배포와 함께 진행해 기존 운영 화면의 로그인을 먼저 막지 않는다.

이미 인증된 계정은 로그인·가입 화면에서 다른 계정으로 덮어쓰지 않는다. 새 계정 인증 전에 네이티브 푸시 등록을 해제하고, 계정 전환은 내 정보의 로그아웃 경로를 거친다.

인증된 사용자 ID가 바뀌면 하위 화면 전체를 새로 마운트해 이전 계정의 목록·상세·입력·펫·프로필 상태를 즉시 버린다. 앱 셸 안쪽만 초기화하면 부모 화면의 기록이 남는다. 같은 사용자 ID의 토큰 갱신은 화면을 다시 마운트하지 않아 작성 중인 초안을 유지한다.
