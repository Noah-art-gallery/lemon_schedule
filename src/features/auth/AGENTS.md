# 인증 모듈

이 모듈은 이메일 가입·로그인·로그아웃과 세션 상태를 소유한다. 프로필 데이터 저장이나 친구 권한 판정은 담당하지 않는다.

가입 입력은 이메일·8자 이상 비밀번호·닉네임·IANA 시간대를 검증하고 Supabase Auth metadata와 프로필 트리거가 같은 값을 사용하게 한다. 검증·Auth 오류는 `AppError`로 변환하며 이메일 확인이 켜진 프로젝트에서는 즉시 로그인 계약을 성공으로 표시하지 않는다.

테스트는 데모 플래그, 설정 누락, 세션 복원, 잘못된 입력, 중복 이메일을 포함해야 한다. 보호 화면은 `AuthProvider`의 상태 전환으로만 판단한다.

이미 인증된 계정은 로그인·가입 화면에서 다른 계정으로 덮어쓰지 않는다. 새 계정 인증 전에 네이티브 푸시 등록을 해제하고, 계정 전환은 내 정보의 로그아웃 경로를 거친다.
