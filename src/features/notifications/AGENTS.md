# 직접 소식 모듈

받은 응원·연결 요청·연결 수락만 목록과 미읽음 배지에 포함한다. 친구 완료는 친구 활동에서 확인하며 기존 완료 이벤트를 삭제하지 않는다.

소식의 대상 ID가 실제로 열린 상세·요청·친구와 일치한 뒤 읽음 처리한다. 읽음 실패는 내용을 가리지 않고 같은 패널에서 재시도하게 한다. 모두 읽음은 마지막 확인 ID 이하의 모든 직접 소식 종류에 적용하며 그 뒤 도착한 소식을 읽음으로 바꾸지 않는다.

계정·선택이 바뀌면 이전 비동기 결과를 무시한다. 추가 페이지에서 고른 소식이 첫 페이지에 없다는 이유로 무효화하지 말고 정확한 ID를 다시 확인한다. 삭제·접근 불가·조회 실패 때 캐시 원문을 남기지 않으며, 권한에 변화 없는 갱신은 열린 작성 폼과 초점을 유지한다.
