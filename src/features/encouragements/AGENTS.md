# 응원 모듈

친구 한 명의 하루에 스티커와 선택 글(120자 이하)을 보낸다. 수신자 시간대의 오늘, 현재 연결, 선택한 발생 건의 소유자·날짜를 서버 RPC가 검증한다. 수신자·작성자·날짜 UNIQUE 제약으로 하나만 저장하며 수정·취소·재전송은 같은 ID와 알림을 유지한다. 다른 친구에게 공개하거나 댓글·대댓글을 만들지 않는다.

`DailyFriendCard`는 친구 목록과 오늘 상세에서 재사용한다. 선택은 초안만 변경하고 명시 전송 성공 후 입력창을 보낸 결과로 교체한다. 실패 시 초안 유지, 중복 전송 방지, 날짜 변경 재조회, 작성자 취소 확인, 계정·권한 상실 시 원문과 초안 제거를 검사한다. 받은 소식은 `DailyEncouragementPanel`에서 정확한 ID를 조회한 후 읽음 처리한다.

기존 `EncouragementThread`는 기록 읽기와 작성자 삭제를 유지한다. 실제 화면은 canCompose=false이며 이전 RPC의 새 쓰기는 거부한다. 수신자의 숨김·삭제 기능은 제공하지 않는다.
