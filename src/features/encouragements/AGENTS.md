# 응원 모듈

완료된 친구 발생 건의 반응과 짧은 메시지만 담당한다. 개인 메시지나 별도 채팅을 추가하지 않는다.

응원은 Supabase `upsert_encouragement` RPC를 통해 현재 연결·완료 상태를 다시 확인한다. 한 작성자와 발생 건의 조합은 하나이며 수정은 같은 행을 갱신한다. 미완료·차단·연결 해제 오류를 화면 성공으로 숨기지 않는다.

목록 응원 요약과 직접 소식은 같은 할 일 상세를 연다. 빠른 반응 변경은 이미 보낸 글을 유지하며 작성 중인 글도 조용히 지우지 않는다. 작성자 삭제와 소유자 숨김·다시 표시를 구분한다. 전송 실패와 늦은 대상 응답을 검증한다.
