# 응원 모듈

완료된 친구 발생 건의 반응·짧은 메시지와 공통 응원 내역·작성 UI를 담당한다. 개인 메시지나 별도 채팅, 소유자 숨김 기능은 제공하지 않는다. 소식 읽음 처리는 이 모듈의 펼침·접기에서 실행하지 않는다.

응원은 `upsert_encouragement` RPC를 통해 현재 연결·완료 상태를 다시 확인한다. 한 작성자와 발생 건의 조합은 하나이며 수정은 같은 행을 갱신한다. 미완료·친구 삭제 오류를 화면 성공으로 숨기지 않는다. 작성자 본인의 응원 삭제만 확인 후 실행한다.

홈·친구 카드와 발생 건 상세는 `EncouragementThread`를 재사용한다. 카드에 응원 수와 최신 작성자·글 또는 반응별 수를 보여 주고 여러 내역을 동시에 펼칠 수 있게 한다. 작성 진입은 응원 남기기·수정 하나이며 반응 선택은 초안만 바꾼다. 보내기·수정 버튼을 누르기 전에는 서버에 쓰지 않는다.

초안은 같은 계정·발생 건의 접힘과 전송 실패 후에도 유지한다. 계정 변경·권한 상실은 원문과 초안을 제거하며 늦은 응답은 요청 세대로 거른다. 숨겨진 내역으로 초점을 보내지 않는다. 펼침 시 쓰기·읽음 없음, 명시 전송, 삭제 취소, 실패 후 초안 유지, 권한 상실 뒤 제거를 검사한다.
