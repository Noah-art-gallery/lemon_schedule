# 할 일 홈 모듈

오늘·예정·기록과 작은 펫 요약을 조합한다. 서버 반환 소유자 오늘을 날짜 분류 기준으로 사용하고, 내일 저장 후 예정으로 이동할 수 있게 한다. 긴 예정 범위와 완료 기록을 초기 목록 수로 잘라 버리지 않는다.

완료 RPC의 최초 완료 여부로만 1포인트 성장 피드백을 연다. 재완료는 보상이나 친구 소식 배지를 늘리지 않는다. 행과 소식은 같은 발생 건 상세로 연결한다. 반복 편집은 발생 건 날짜가 아닌 작업 원본의 기준일을 읽는다. 삭제된 완료 기록은 읽기 전용으로 남긴다.

기존 할 일 목록을 다시 조회하는 동안 행을 언마운트하지 않아 상세를 열었던 버튼의 초점을 보존한다. 성공 결과의 삭제·날짜 이동·밀린 항목 완료로 원래 행이 없어지면 같은 발생 건의 현재 행, 없으면 할 일 추가로 복귀한다. 조회 실패는 이전 목록을 비우고 재시도를 제공하며 빈 목록으로 표현하지 않는다.
