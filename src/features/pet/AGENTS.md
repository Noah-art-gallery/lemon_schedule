# 개인 펫 모듈

본인의 그림·포인트·성장·해금 꾸미기를 담당한다. 친구에게 원본이나 signed URL을 노출하지 않는다. 5점 성장 단위와 5·15·30점 해금을 서버 결과와 맞춘다.

저장은 새 PNG 경로 업로드 후 소유자의 그림 경로를 갱신한다. 실패가 기존 그림을 덮어쓰지 않도록 upsert하지 않는다. 미참조 이전 파일의 자동 정리는 현재 없다. 그림을 버린 뒤 늦게 도착한 캔버스 변환 결과는 저장하지 않는다.

꾸미기 권한은 서버가 다시 확인한다. 저장 중 중복 실행을 막고 실패 시 그림과 선택을 보존한다. 데모는 화면 간 그림·꾸미기·포인트를 공유하며 Blob URL은 화면을 나갈 때 폐기하지 않는다.
