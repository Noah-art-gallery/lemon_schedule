# 펫 모듈

사용자 한 명의 그림·포인트·레벨·해금 꾸미기를 표시하고 도화지 입력과 저장을 담당한다. 친구 화면이나 다른 사용자 프로필에 펫 원본을 노출하지 않는다.

캔버스는 포인터 입력과 터치 입력을 같은 경로로 처리하고, 저장은 PNG Blob을 사용자 UUID 경로에 upsert한다. 그림이 없거나 signed URL을 만들 수 없으면 기본 레몬을 보여 주되 저장 오류는 상태 메시지로 알린다.

꾸미기 선택은 서버 RPC가 해금 목록을 다시 확인한다. 색상은 도화지 붓 색상에, 스티커와 배경은 개인 펫 화면에 적용한다. 미해금 항목을 화면에서 비활성화해도 서버 검사를 생략하지 않는다.
