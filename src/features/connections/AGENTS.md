# 친구 연결 모듈

초대 요청·수락·거절·취소, 친구 조회·연결 해제·차단을 소유한다. 기본 화면은 친구의 최근 완료 활동이며, 친구 선택 후 소유자의 오늘 기준으로 오늘·밀린·예정·기록을 분류한다.

차단과 연결 해제는 친구 관리 메뉴 안에 두고 대상 이름을 확인한다. 취소는 관리 버튼, 성공은 남은 화면의 유효한 진입점으로 초점을 옮긴다. 서버 성공 직후 공유 캐시를 비우고 뒤따른 목록 갱신 실패를 관계 변경 실패로 표현하지 않는다. 무관한 연결 갱신은 작성 중인 응원글을 지우지 않는다.

변경은 보안 RPC를 사용한다. 계정 전환과 해당 관계 삭제 시 이전 조회·상세 응답을 반영하지 않는다. 비연결·차단 상태는 공유 읽기와 새 요청보다 우선한다. 응원 쓰기는 공통 발생 건 상세와 완료 항목 권한을 사용한다.
