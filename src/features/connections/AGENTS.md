# 친구 연결 모듈

이 모듈은 초대 요청·수락·거절·취소, 친구 조회, 연결 해제, 차단을 소유한다. 할 일 완료나 알림 생성의 원자 처리는 소유하지 않는다.

모든 변경은 보안 RPC를 사용하고, 화면에 닉네임만 표시한다. 친구 현황은 `get_owner_today`와 `list_task_occurrences` 결과로 소유자 시간대의 오늘·밀린·미래 항목을 분류한다. 연결 해제·차단 후 화면 상태도 즉시 닫는다.

요청 중복·자기 초대·차단 중 재요청과 비연결 조회를 검증한다. 응원 버튼은 완료 항목에만 노출하고 메시지 입력 실패를 성공으로 바꾸지 않는다.
