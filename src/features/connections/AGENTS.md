# 친구 연결 모듈

초대 요청·수락·거절·취소, 친구 조회·삭제를 소유한다. 기본 화면은 사람별 오늘 완료 현황·할 일 요약·하루 응원 카드이며, 친구 선택 후 소유자의 오늘 기준으로 오늘·밀린·예정·기록을 분류한다. 요청 진입과 친구 선택·관리는 구분한다.

친구 삭제는 관리 메뉴 안에 두고 대상 이름과 공유 종료 결과를 확인한다. 취소는 관리 버튼, 성공은 남은 화면의 유효한 진입점으로 초점을 옮긴다. 서버 성공 직후 공유 캐시·응원 초안을 비우고 뒤따른 목록 갱신 실패를 삭제 실패로 표현하지 않는다. 삭제 실패 시 기존 관계를 유지하며 다시 연결하려면 새 요청과 수락이 필요하다.

변경은 보안 RPC를 사용한다. 계정 전환과 해당 관계 삭제 시 이전 조회·상세 응답을 반영하지 않는다. 무관한 요청 갱신은 작성 중인 응원글을 지우지 않는다. 친구 카드·오늘 일정은 공통 DailyFriendCard를, 과거 응원은 읽기 전용 내역을 사용하고 별도 응원 저장이나 차단 기능을 구현하지 않는다. 재조회 실패·외부 관계 삭제·늦은 응답·취소 초점 복귀를 검사한다.
