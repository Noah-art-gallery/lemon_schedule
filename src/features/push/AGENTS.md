# 휴대폰 알림 연결

Capacitor Push Notifications 권한·토큰·기기 ID 등록만 담당한다. 완료 상태와 앱 안 알림의 신뢰 원천은 이 모듈에 두지 않는다.

네이티브 플랫폼이 아니거나 권한을 거부하면 `{ active: false }`를 반환하고 핵심 완료 흐름을 실패시키지 않는다. 토큰은 사용자와 기기 ID의 조합으로 upsert하며 로그아웃 시 해당 행을 삭제한다. 같은 휴대폰에서 다른 계정이 로그인하면 동일한 APNs/FCM 토큰을 재사용할 수 있으므로 비활성 행을 남기지 않는다.

로그아웃·새 계정 인증 전·세션 종료 이벤트에는 OS 푸시 등록도 해제한다. 기기 토큰 서버 등록이 실패하면 OS 등록을 다시 해제해 다른 계정의 오래된 토큰으로 수신하지 않게 한다. 실기기 두 계정 검증 전에는 이 경로를 출시 검증 완료로 표시하지 않는다.

받은 응원·연결 요청·연결 수락만 휴대폰에 알린다. task_completed 탭과 일반 완료 전용 이동을 새 알림으로 취급하지 않는다. 켜짐은 OS 권한과 현재 계정·기기의 서버 행을 함께 확인한 결과다. 등록·해제와 로그아웃을 직렬화해 늦은 등록 결과가 종료된 계정에 토큰을 되살리지 않게 한다.
