# 할 일 모듈

입력·반복·완료 계약과 공통 발생 건 상세를 소유한다. 홈·친구·소식은 같은 상세와 응원 폼을 사용하며 친구 쓰기 권한을 화면만으로 판단하지 않는다.

월 반복은 작업 원본 due date의 일자를 보존한다. 완료·삭제 기록은 일정 수정으로 다시 쓰지 않는다. 서비스는 큰 날짜 범위를 나누고 행 페이지를 끝까지 읽어 1년이나 20건에서 조용히 끝나지 않게 한다.

제목·시간·반복 입력을 검증하고 시간 제거는 null로 전달한다. 완료 응답의 최초 완료·보상 여부를 기준으로 성장 피드백을 표시한다. 대상 전환과 늦은 응답은 현재 선택을 확인하며 저장 실패가 작성 중 입력을 버리지 않게 한다. 편집·숨김 후 사라지는 버튼 대신 상세 내부의 유효한 요소로 초점을 옮긴다.

개발 데모는 할 일·계정·펫·연결 상태를 한 메모리 저장소에 유지한다. 새로고침 시 초기화하며 실제 저장 성공으로 보고하지 않는다.
