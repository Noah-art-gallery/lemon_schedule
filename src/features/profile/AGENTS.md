# 내 정보 모듈

닉네임·시간대·초대 코드·포인트 요약·차단 목록·로그아웃을 담당한다. 이메일을 화면에 표시하거나 친구 권한을 직접 판단하지 않는다.

프로필 수정은 `update_my_profile` RPC의 생략 필드 유지 계약을 사용한다. 시간대 변경 후 홈 조회가 새 소유자 오늘을 사용하는지 확인하고, 차단 해제는 연결을 자동 복원하지 않는다.

휴대폰 알림은 웹·꺼짐·거부·켜짐·확인 중·실패를 구분하며 OS 허용만으로 켜짐을 표시하지 않는다. 차단 목록은 친구 관리의 실제 변경과 일치해야 하며, 데모에서도 같은 상태를 공유한다.
