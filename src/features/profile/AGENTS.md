# 내 정보 모듈

닉네임·선택형 프로필 이모지·시간대·초대 코드·로그아웃을 담당한다. 이메일을 화면에 표시하거나 친구 권한을 직접 판단하지 않는다.

프로필 수정은 `update_my_profile` RPC의 생략 필드 유지 계약을 사용한다. `avatarKey`는 고정된 8종 키만 보내고 직접 테이블 갱신이나 펫 이미지 경로를 사용하지 않는다. 선택만으로 저장하지 않으며 취소·전송 실패 때 선택 상태와 이전 저장값을 구분한다. 저장된 선택은 공통 `ProfileAvatar`로 표시하고 닉네임 첫 글자를 아바타로 만들지 않는다. 시간대 변경 후 홈 조회가 새 소유자 오늘을 사용하는지 확인한다. 수정 패널을 닫을 때 미저장 입력을 확인하며 실패 후 값을 유지한다.

휴대폰 알림은 웹·꺼짐·거부·켜짐·확인 중·실패를 구분하며 OS 허용만으로 켜짐을 표시하지 않는다. 차단 목록과 관계 관리를 이 화면에 추가하지 않는다. 데모 프로필 변경도 화면 간 같은 상태를 공유한다.
