# 레몬스케줄 캐릭터 리소스

사용자가 승인한 2D 시안의 그림체로 2026-10-12 제작한 투명 배경 PNG 원본이다. 홍보 이미지나 애니메이션 프레임이 아닌 정적 캐릭터 atlas이며, 실제 파일 크기는 1254 × 1254px이다.

| 행  | 왼쪽부터 순서                      |
| --- | ---------------------------------- |
| 1   | 프로필: 레몬, 고양이, 강아지, 토끼 |
| 2   | 프로필: 곰, 여우, 펭귄, 튤립       |
| 3   | 응원: 레몬, 박수, 좋아요, 응원     |
| 4   | 펫: 기본, 휴식, 손인사, 기쁨       |

`src/components/ui/character-sprite.tsx`가 각 그림의 원본 좌표를 소유한다. 생성 원본의 셀별 여백이 정확히 같지 않으므로 단순한 4등분 좌표로 사용하지 않는다. 각 그림의 경계를 잘라 표시하고, 종횡비를 보존하며 512 × 512 공통 viewport 안에 가운데 정렬한다. 긴 변은 432 단위, 최소 여백은 양쪽 40 단위다. 앱에서는 프로필 24–48px, 응원 내역 32–56px·선택 48px, 로고 30px, 기본 펫 최대 240px로 축소 표시한다. 정규화는 렌더링 시 적용하며 PNG 원본을 늘이거나 변형하지 않는다.

프로필 8종, 응원 4종, 기본 펫을 현재 앱에서 사용한다. 휴식·손인사·기쁨은 이번 원본에 포함된 예비 그림이며 현재 응원 선택지나 보상 상태에 연결하지 않는다. DB에는 기존 `avatar_key`와 반응 키를 그대로 저장한다. 개인이 그린 펫은 기존 비공개 그림 경로를 사용한다.

그림 교체 시 원본 PNG와 좌표를 함께 갱신하고 버전이 있는 파일명을 사용한다. 기존 Twemoji SVG와 해당 라이선스 고지는 원래 폴더에 보존되어 있으나 현재 앱의 캐릭터 표시는 이 atlas를 사용한다.
