# 제품 규칙

사용자는 초대 코드로 승인형 친구 연결을 만든다. 수신자만 수락·거절하고 발신자만 취소한다. 친구 삭제는 친구 관리에서 대상 이름과 서로의 할 일 공유가 끝난다는 결과를 확인한 뒤 실행한다. 확인창의 첫 초점은 취소다. 성공하면 공유 화면과 작성 중 응원을 비우며, 삭제 실패는 관계를 유지한다. 성공 뒤 목록 갱신만 실패한 경우에도 삭제는 성공으로 유지한다. 다시 친구가 되려면 새 요청과 상대 수락이 필요하며 자동 재연결은 없다. 차단 기능은 제공하지 않는다.

프로필은 닉네임 첫 글자 대신 사용자가 고른 2D 캐릭터를 표시한다. 레몬·고양이·강아지·토끼·곰·여우·펭귄·튤립 중 하나를 고르며 처음에는 레몬이다. 내 정보의 수정 화면에서 선택한 뒤 저장해야 적용되고 취소하면 이전 캐릭터를 유지한다. 친구 목록과 완료 활동에도 같은 선택을 표시하며 펫 그림과는 별개다.

할 일 제목은 공백이 아닌 80자 이하이고 날짜가 필수다. 반복은 없음·매일·매주·매월이다. 매월 31일 일정은 짧은 달에 말일을 사용하되 다음 달의 기준일을 28일로 바꾸지 않는다. 오늘은 소유자 시간대를 기준으로 한다. 지난 미완료는 밀린 항목에 남고, 예정 범위와 완료 기록은 추가 조회할 수 있다. 삭제한 할 일의 최초 완료 기록은 읽기 전용으로 남는다.

완료 버튼은 아이콘과 완료·완료됨 문구를 함께 표시하며 제목을 눌러 여는 상세와 분리한다. 완료 직후 목록 순서를 바꾸거나 행을 숨기지 않고 밀린 항목도 현재 화면에 남긴다. 요청 중 같은 항목을 다시 실행하지 않으며 실패는 해당 항목에서 재시도할 수 있다. 제목·날짜는 입력 폼에서 항상 보이고 시간·반복은 접어도 입력값을 유지한다.

소유자의 최초 완료만 완료 시각·1 레몬 포인트·완료 이벤트를 만든다. 취소는 현재 상태만 미완료로 돌리며 보상을 회수하지 않는다. 재완료·연속 클릭·동시 요청은 추가 보상과 최초 완료 축하를 만들지 않는다. 친구의 완료 소식은 친구 화면에서 확인하며 소식 배지나 휴대폰 알림에 포함하지 않는다.

현재 친구의 하루에 스티커 하나와 선택 응원글(120자 이하)을 보낸다. 기준일은 수신자의 시간대이며 한 작성자·수신자·날짜 조합에 하나만 저장한다. 할 일이 없거나 미완료여도 보낼 수 있다. 같은 수신자의 오늘 할 일 하나를 선택해 인용할 수 있으며 댓글이나 대댓글은 만들지 않는다. 응원은 작성자와 수신자만 확인하며 다른 친구에게 공개하지 않는다.

스티커 선택은 초안만 바꾸고 보내기를 눌러야 저장한다. 성공하면 입력창 대신 스티커·글·선택 인용과 보냄 상태를 표시한다. 수정은 같은 행을 갱신하고 취소 후 재전송도 같은 ID를 복원하므로 알림이 반복 생성되지 않는다. 작성자만 확인 후 취소할 수 있다. 날짜가 바뀐 초안은 서버가 거부하고 오늘을 다시 불러오면 초기화한다. 실패 시 초안을 유지하고 화면 이탈은 미전송 내용을 확인한다. 계정 변경·권한 상실은 원문과 초안을 제거한다.

기존 할 일별 응원은 읽기와 작성자 삭제만 유지하며 새 작성·수정은 거부한다. 친구 삭제 후 수신자는 과거 응원을 보되 작성자 이름과 캐릭터는 가려진다. 발신자는 공유 읽기·수정을 할 수 없고 본인의 과거 응원 취소만 할 수 있다.

소식은 받은 응원·연결 요청·연결 수락만 표시한다. 내용을 실제로 열어 대상이 확인된 뒤 읽음 처리하며 실패하면 재시도를 제공한다. 모두 읽음은 확인한 마지막 소식 ID까지만 적용하므로 이후 도착한 소식은 읽지 않은 상태로 남는다. 읽음 실패가 내용 열람을 막지 않는다. 휴대폰 알림도 같은 세 종류이며 잠금 화면에는 응원글·할 일 제목을 넣지 않는다.

개인 펫은 본인만 본다. 최초 완료 1건당 1점, 5점마다 성장 단계가 올라간다. 5점에 노란 붓, 15점에 잎사귀 모자, 30점에 햇살 정원이 열린다. 그림이 없으면 기본 레몬을 표시하며 저장 실패는 기존 그림을 보존한다. 데모는 화면 간 변경을 유지하지만 새로고침하면 초기 샘플로 돌아가며 실제 계정에 저장되지 않는다.

응원 반응은 선택·받은 내역·요약에서 같은 그림으로 표현한다. 반응 이름은 접근성 설명으로 제공하며 그림 대신 본문 텍스트로 출력하지 않는다. 선택만으로 전송하지 않고 선택 상태를 색과 체크로 함께 구분한다.
