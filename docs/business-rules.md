# 제품 규칙

모든 사용자는 같은 일반 사용자이며 초대 코드로 승인형 연결을 만든다. 대기 요청은 수신자만 수락·거절하고 발신자만 취소한다. 연결 해제와 차단은 공유 조회와 새 요청을 즉시 끊으며, 차단 해제는 연결을 복원하지 않는다.

할 일 제목은 공백이 아닌 80자 이하이고 날짜가 필수다. 반복은 없음·매일·매주·매월이며, 월 기준일이 없는 달에는 그 달의 마지막 날짜를 사용한다. 각 날짜 발생 건은 독립적으로 완료되고, 지난 미완료 건은 사라지지 않는다. 삭제는 논리 삭제이고 완료 사건과 이미 지급된 포인트는 유지한다.

소유자의 최초 완료만 완료 시각·1 레몬 포인트·연결 사용자별 완료 알림을 함께 만든다. 완료 취소는 현재 상태만 pending으로 돌리고 최초 완료·포인트·최초 알림은 되돌리지 않는다. 같은 발생 건의 재완료와 동시 요청은 추가 보상을 만들지 않는다.

응원은 현재 연결된 사용자가 완료된 발생 건에만 남긴다. 반응이나 120자 이하 글 중 하나 이상이 필요하고, 한 작성자는 발생 건마다 하나의 응원을 갱신한다. 작성자는 삭제하고 소유자는 숨길 수 있다. 완료 취소·연결 해제 뒤에는 소유자 기록에서만 과거 응원을 볼 수 있다.

펫은 사용자마다 하나이며 그림과 성장 정보는 본인만 본다. 최초 완료마다 1점을 얻고 기본 단계는 5점 단위로 다음 단계로 올라간다. 그림이 없으면 기본 레몬을 보이고, 저장 시 기존 그림을 덮어쓴다. 5점에 노란 붓 색, 15점에 잎사귀 모자, 30점에 햇살 정원이 열리며, 해금 전에는 선택할 수 없다. 기본 초록 붓 색·꾸미기 없음은 포인트와 무관하게 선택할 수 있다.
