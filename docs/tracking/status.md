# 현재 상태

## 구현됨

- 오늘·예정·기록을 분리한 할 일 화면, 서버 소유자 오늘 기준, 반복 원본 수정, 삭제 후 완료 기록 보존, 최초 완료만 1포인트 지급
- 할 일 행과 받은 응원 소식에서 같은 상세 패널 열기, 반응·응원글 작성/수정/삭제, 소유자 숨김/다시 표시, 실패와 대상 전환 시 입력 보호
- 친구 최근 완료 활동과 친구별 오늘·밀린·예정·기록, 커서와 날짜 범위 추가 조회, 친구 추가·받은 요청·보낸 요청을 한 패널에 배치
- 친구 관리에서 이름을 확인하는 차단·연결 해제, 성공 즉시 공유 화면 제거, 실패 시 관계 보존, 차단 해제 후 비연결 유지
- 받은 응원·연결 요청·수락만 소식과 배지에 표시, 정확한 대상 확인 뒤 읽음 처리, 마지막 확인 ID까지 모두 읽음, 직접 소식 전용 휴대폰 발송 정책
- 간결한 인증·내 정보·펫 화면, 개인 PNG 버전 저장, 해금 꾸미기, 실제 OS 권한과 서버 등록을 반영하는 휴대폰 설정
- 중립색 앱 셸과 제한된 레몬 강조, 좁은 화면 패널과 키보드 초점 관리, 화면 간 할 일·프로필·펫·차단 상태를 공유하는 개발 데모

## 검증됨

2026-10-12 주요 기능 통합 상태에서 포맷·린트·앱 타입·서버 함수 타입·단위 검사·SQL 정적 계약·정적 빌드가 통과했다. 당시 단위 검사는 152개 통과와 실제 계정 의존성 2개 건너뜀이었다. 이후 공유 데모 상태·다년 범위·20건 초과 기록·초점 회귀 검사를 포함한 단위 검사 159개가 통과하고 외부 의존성 2개를 건너뛰었다. 포맷·린트·앱 타입 검사도 통과했다. 마지막 변경을 포함한 전체 일괄 검사와 독립 검토는 아직 확정 전이다.

격리된 로컬 DB의 빈 상태에서 12개 migration 적용이 성공했고 pgTAP 보안 18개·행동 150개·웹훅 12개, 총 180개가 통과했다. 이 결과는 원격 프로젝트에 새 migration을 적용했다는 뜻이 아니다.

실제 브라우저의 데모 화면에서 할 일 추가·수정·완료·재완료, 내일 일정의 예정 진입, 응원글 전송 뒤 반응 변경, 소식에서 같은 응원 열기와 모두 읽음, 친구 관리 취소·요청 수락, 펫 그리기·프로필 취소를 확인했다. 360·390·430px 프레임과 1440px 데스크톱 캡처를 사용했다. 글자 200% 확인은 CSS 시뮬레이션이며 실제 OS 글자 확대가 아니다. 줄인 동작 미디어 설정은 CSS 규칙을 확인했고 실제 기기 설정 전환은 미검증이다. 정확히 80자 제목과 40자 닉네임의 줄바꿈·가로 넘침 없음, 화면 간 3포인트 일치, 430px 펫 선택란 정렬, 차단 확인 Enter 취소 뒤 관리 버튼 초점과 실제 차단 뒤 친구 추가 초점을 확인했다. 안정된 마지막 코드에서 차단 해제 후 패널 안내문 초점, 닫은 뒤 차단 목록 진입점 복귀, 해제 후에도 친구가 다시 연결되지 않음을 재확인했다. 마지막 받은 요청 수락 후 목록 제목 초점과 패널 닫기 후 친구 추가 진입점 복귀도 확인했다. 응원 숨김 후 상세 내부 초점은 단위 회귀 검사로 확인했다. 자동 브라우저 검사 정의는 갱신했지만 이번 변경에서 실행하지 않았다.

2026-10-03 원격 프로젝트의 기존 이메일 가입·로그인·동시 완료·차단 경합 API 검사는 성공했으며 당시 테스트 계정은 정리했다. 기존 10개 migration, 발송 함수 v1, Android Firebase 설정과 웹훅·Vault 연결은 당시 검증 기록이다. 이 과거 결과를 새 조회 RPC·직접 소식 발송 정책의 원격 검증으로 사용하지 않는다.

## 남은 일

- 새 읽기 모델과 펫 경로 migration 두 개 및 직접 소식 발송 함수 변경을 원격에 적용하고 실제 두 계정으로 조회 권한·동작을 검증한다.
- Android 네이티브 빌드·기기 설치, iOS 서명·APNs 자격, 실제 알림 수신·정확한 탭 이동·권한 거부·계정 전환을 검증한다.
- 강제 세션 만료 뒤 남은 서버 토큰 행과 같은 기기 새 계정 등록 충돌을 실제 기기로 확인한다. 해결 전 휴대폰 푸시 출시 완료로 판단하지 않는다.
- 미참조 펫 그림 파일 자동 정리는 구현하지 않았다. 원본 참조를 보호하는 운영 정리 정책이 필요하다.
- 배포 도메인과 이메일 운영 설정을 확정한다. 이번 화면 개편은 로컬 구현이며 배포하지 않았다.
