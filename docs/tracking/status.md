# 현재 상태

## 구현됨

- 오늘·예정·기록을 분리한 할 일 화면, 서버 소유자 오늘 기준, 반복 원본 수정, 삭제 후 완료 기록 보존, 최초 완료만 1포인트 지급
- 제목 상세 진입과 분리한 48px 완료·완료됨 버튼, 완료 직후 행 순서·밀린 항목·초점 유지, 시간·반복을 접어도 값이 남는 입력 폼
- 홈·친구·상세가 공유하는 응원 내역, 카드별 수·최신 작성자와 글 또는 반응 수, 여러 카드 펼침과 초안 유지, 명시적 전송·수정과 작성자 삭제 확인
- 친구 최근 완료의 작성자·할 일·시각·응원 순서, 요청·선택·관리 구분, 관리 메뉴의 친구 삭제와 재추가 시 승인, 삭제 성공 직후 공유 캐시 제거와 실패 시 관계 보존
- 차단 UI·서비스·DB와 소유자 응원 숨김 제거, 기존 소유자 숨김만 공개 복원, 작성자 삭제·기존 계정·할 일·보상·이벤트·요청 기록 보존
- 받은 응원·연결 요청·수락만 소식·배지·휴대폰 발송 대상, 정확한 대상 확인 뒤 읽음 처리, 마지막 확인 ID까지 모두 읽음
- 그림과 성장 정보를 구분한 펫 화면, 개인 PNG 버전 저장·해금 꾸미기, 프로필 편집 패널과 미저장 입력 보호, 실제 OS 권한·서버 등록을 반영하는 휴대폰 설정
- 내 정보에서 8종 이모지 선택·저장, 친구 목록·완료 활동에 동일 선택 표시, 응원·소식의 작성자 이모지 조회와 관계 종료 후 기본값 처리
- 응원 선택·받은 내역·요약의 공통 그림 반응, 이름을 접근성 설명으로 제공하고 선택 상태를 그림·색·체크로 구분
- 16px 본문·입력과 공통 버튼·초점 관리, 짧은 내용에 맞는 모바일 패널, 화면 간 할 일·프로필·펫·연결 상태를 공유하는 개발 데모

## 검증됨

2026-10-12 선택형 프로필 이모지와 동시 응원 조작·뒤로가기 보완을 포함한 통합 코드에서 아래 검사를 통과했다. 단위 검사는 244개 통과, 실제 계정 의존성 2개 건너뜀이다. 최초 병렬 실행은 시간 초과와 후속 DOM·초점 검사 19개가 실패했다. 소스·테스트·제한 시간을 바꾸지 않고 `VITEST_MAX_WORKERS=1`로 재실행해 전체 통과를 확인했다. 아래 단위 검사 결과는 이 단일 worker 실행 기준이다.

| 실행 명령                  | 종료 코드 |
| -------------------------- | --------- |
| `npm run format:check`     | 0         |
| `npm run lint`             | 0         |
| `npm run typecheck`        | 0         |
| `npm run typecheck:edge`   | 0         |
| `npm test -- --run`        | 0         |
| `npm run test:db-contract` | 0         |
| `npm run build`            | 0         |

격리된 로컬 DB의 빈 상태에서 14개 migration 적용이 성공했고 `pg_prove`로 SQL 파일 5개·검사 210개가 통과했다. 기존 12개 migration에 소유자 숨김·작성자 삭제·연결 해제 데이터를 만든 뒤 13번째 migration을 적용한 업그레이드 검사도 38개 통과했다. 별도 13→14 업그레이드는 기존 공개·비공개 프로필의 모든 필드를 보존하고 기본 `avatar_key: lemon`만 추가함을 확인했다. 원격 프로젝트에는 새 migration을 적용하지 않았다.

실제 브라우저 데모에서 할 일 추가·완료·취소, 완료 버튼 초점과 당일·밀린 행 유지를 확인했다. 360·430px 프레임에서 80자 한글 제목의 가로 넘침이 없고 완료 버튼 높이는 48px였다. 데스크톱 본문 폭은 800px였다. 펫은 그리기 후 닫기 확인에서 계속 편집에 첫 초점이 놓이고 펜으로 초점이 돌아온 뒤 저장됨을 확인했다. 프로필은 40자 입력 후 취소·계속 편집에서 내용과 입력 초점을 유지하고 저장됐다.

360px 친구 화면에서 서로 다른 카드의 120자·10자 응원 초안을 동시에 유지하고 접었다 펼친 뒤 각각 전송했다. 접힌 카드에도 최신 글 미리보기가 표시됐다. 이는 데모 UI 증거이며 실제 계정 저장·보상 검증을 뜻하지 않는다. 받은 응원에서 정확한 글 펼침·초점과 배지 3→2, 닫은 뒤 원래 소식 행으로 초점 복귀를 확인했다. 친구 요청 수락과 목록 갱신, 삭제 취소 후 관리 버튼 복귀, 삭제 성공 후 해당 공유 활동 제거·친구 추가 초점도 확인했다. 데모의 임의 초대 코드 요청은 수락 대기로 표시됐으며 동일 친구의 승인형 재추가는 로컬 DB 검사로 확인했다.

친구 화면에서 초안 작성 후 내 정보로 이동을 승인하고, 뒤로가기로 재진입해 새 초안을 작성했다. 뒤로가기 취소는 입력과 초점을 보존하고 승인하면 원래 홈 URL과 화면으로 돌아왔다. 360px 프로필의 40자 닉네임은 가로 넘침 없이 저장됐고, 펫 430px와 인증 360px·데스크톱 배치를 캡처로 확인했다. 360px 글자 200% CSS 시뮬레이션에서 긴 추가 조회 버튼의 줄바꿈을 보완한 뒤 문서 가로 폭 345px 안에 들어옴을 확인했다. 실제 OS 확대나 기기 키보드를 검증한 결과는 아니다.

360px 브라우저 데모에서 프로필 선택 화면의 체크 상태와 고양이 저장, 친구 목록·완료 활동 사이의 프로필 이모지 일치, 소식 작성자 이모지와 받은 박수 그림 표시를 확인했다. 이 검증은 로컬 데모이며 원격 두 계정 간 프로필 변경 전파 검증은 아니다.

자동 브라우저 검사 정의는 인라인 응원·명시 전송·친구 삭제와 접힘 입력값 보존에 맞춰 갱신했으며 이번 변경에서는 자동 실행하지 않았다. 단위 검사·정적 검사·실제 브라우저 조작을 같은 증거로 취급하지 않는다.

2026-10-03 원격 프로젝트의 기존 이메일 가입·로그인·동시 완료 검사는 당시 검증 기록이다. 기존 10개 migration, 발송 함수 v1, Android Firebase 설정과 웹훅·Vault 연결도 같은 시점의 결과이며 새 조회·정책·직접 소식 발송의 원격 검증으로 사용하지 않는다.

## 남은 일

- 읽기 모델·펫 경로·차단 및 소유자 숨김 제거·프로필 이모지 migration 네 개와 직접 소식 발송 함수 변경을 원격에 적용하고 실제 두 계정으로 조회 권한·동작을 검증한다.
- Android 네이티브 빌드·기기 설치, iOS 서명·APNs 자격, 실제 알림 수신·정확한 탭 이동·권한 거부·계정 전환을 검증한다.
- 실제 휴대폰 키보드·안전 영역·OS 글자 확대·줄인 동작 설정을 확인한다. 브라우저 프레임이나 CSS 시뮬레이션은 이 검증을 대체하지 않는다.
- 강제 세션 만료 뒤 남은 서버 토큰 행과 같은 기기 새 계정 등록 충돌을 실제 기기로 확인한다. 해결 전 휴대폰 푸시 출시 완료로 판단하지 않는다.
- 미참조 펫 그림 파일 자동 정리는 구현하지 않았다. 원본 참조를 보호하는 운영 정리 정책이 필요하다.
- 배포 도메인과 이메일 운영 설정을 확정한다. 이번 화면 개편은 로컬 구현이며 배포하지 않았다.
