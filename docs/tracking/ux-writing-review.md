# UX 문구 점검 · 2026-11-03

소식·친구·할 일·응원·펫·내 정보·가입/로그인의 화면 문구와 사용자에게 표시하는 검증 오류를 점검했다. 기존 작업 내용 위에 문구와 해당 화면 검사를 갱신했다.

## 문구 기준

- 화면 분류는 사용자가 확인할 내용을 구체적으로 적는다.
- 친구 관계는 ‘친구 추가·친구 요청·친구가 됐어요’로 표현한다. 서버 계약의 connection 키는 유지한다.
- 안내는 ‘해요’체를 사용하고, 버튼에는 실행 결과를 알 수 있는 동사를 쓴다.
- 오류는 사용자가 확인할 항목이나 다음 행동을 안내한다. 내부 설정 파일명과 제품명을 해결 방법으로 제시하지 않는다.
- 성장 수치 단위는 ‘포인트’로 통일한다.

## 주요 변경

| 기존                          | 변경                                            |
| ----------------------------- | ----------------------------------------------- |
| 전체 / 응원 / 연결            | 전체 / 받은 응원 / 친구 소식                    |
| ○○의 연결 요청                | ○○님이 친구 요청을 보냈어요                     |
| ○○님과 연결됐어요             | ○○님과 친구가 됐어요                            |
| 초대 코드로 친구 연결         | 초대 코드로 친구 추가                           |
| 모두 읽음                     | 모두 읽음으로 표시                              |
| 오늘 응원 보냄 · 수정         | 보낸 응원 수정하기                              |
| 다음 실천을 기다리는 중이에요 | 아직 친구 활동이 없어요                         |
| 변경 저장 / 수정 저장         | 수정 완료                                       |
| 변경 버리기 / 그림 버리기     | 버리고 닫기                                     |
| 할 일을 입력하세요            | 어떤 일을 할까요?                               |
| 반복 일정 전체를 수정합니다…  | 바뀐 내용은 앞으로의 반복 일정에 모두 적용돼요… |
| 그리기 붓 색상 / 농도         | 펜 색상 / 진하기                                |
| 실제 저장 안 됨               | 새로고침하면 초기화돼요                         |

닉네임 길이·빈 입력·시간대·할 일 제목 길이 오류에 한국어 안내를 명시했다. 가입 이메일 인증 대기 시 개발 설정 변경 대신 인증 메일 확인과 로그인을 안내한다. 시간대 입력에는 예시와 용도를 추가했다.

## 검증

- 포맷·린트·앱 타입·Edge 타입·SQL 정적 계약·정적 빌드가 통과했다. 단위 검사는 257개 통과·2개 건너뜀이다.
- ego-browser로 실행 중인 별도 데모 서버 `http://localhost:3000`에서 소식 필터 전환과 친구 추가·할 일 작성·프로필 수정 패널을 조작했다.
- 주요 화면 5개를 360·390·430·1024px에서 확인했으며 페이지 가로 넘침이 없었다.
- 할 일 80자와 닉네임 40자 입력을 확인했다. 360px에서 소식 버튼 글자를 32px로 확대해 필터 문구가 글자 단위로 끊기는 문제를 확인하고, 필터가 버튼 단위로 줄바꿈하도록 보완했다.
- 검증 중 발견한 기존 테스트 호환성 문제도 수정했다. Testing Library에서 지원하지 않는 `exact` 옵션을 제거하고 UUID 샘플을 유효한 형식으로 바꿨다. 요청 카운터 ref의 정리 의도를 명시해 린트 경고를 해소했다.
- 화면 캡처는 `output/ux-writing/`에 남겼다. 데모 확인은 실제 계정·DB 저장·휴대폰 알림 검증을 의미하지 않는다.
- 자동 Playwright E2E는 실행하지 않았으며 브라우저 확인은 ego-browser로 수행했다. 프로필 성공 안내 검사는 패널이 닫힌 뒤 토스트가 옮겨질 때까지 기다리도록 보완했다.
