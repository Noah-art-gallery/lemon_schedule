# 승인형 친구 삭제와 카드 안 응원

## 배경

작은 완료 아이콘과 제목 진입을 구분하기 어렵고 응원을 보려면 상세를 열어야 해 목록에서 할 일과 친구 반응을 함께 확인하기 어려웠다. 차단·해제와 소유자 숨김·다시 표시까지 병행하면 관계 권한과 응원 표시 상태를 각각 관리해야 했다.

## 선택

제목과 완료 행동을 분리하고 완료 직후 행을 유지한다. 응원 수·최신 글은 카드에 표시하며 여러 내역을 동시에 펼칠 수 있게 한다. 반응 선택은 초안이며 보내기·수정을 눌러야 저장한다. 접기 자체는 데이터 변경이나 소식 읽음이 아니다.

관계 정리는 친구 삭제로 통일한다. 공유 종료를 확인하고 삭제하며 다시 연결하려면 요청과 상대 수락을 거친다. 응원은 작성자만 삭제할 수 있다. 차단과 소유자 숨김 기능은 제거하고 기존 소유자 숨김만 공개 상태로 복원한다.

## 대안

응원 작성과 열람을 상세 패널에만 두면 목록이 짧아지지만 친구 반응을 보거나 여러 할 일을 비교할 때 반복 진입이 필요하다. 차단과 소유자 숨김을 유지하면 상대 재요청 차단과 개별 글 표시 제어를 제공할 수 있지만 삭제·해제·숨김·복원 사이의 상태와 권한 조합이 늘어난다. 현재 제품은 승인형 연결과 작성자 삭제만 유지한다.

## 결과

홈·친구·상세의 응원 UI는 같은 동작과 권한을 사용해야 한다. 펼친 카드별 초안·초점과 실패 복구를 관리해야 하며 권한을 잃으면 과거 원문을 비운다. 친구 삭제는 재요청 자체를 금지하지 않고 기존 친구를 자동 복원하지도 않는다. 소유자가 다른 작성자의 응원을 개별 숨김 처리할 수는 없다. 기존 완료·보상·요청 기록을 보존하며 상태 복원으로 새 알림을 만들지 않는다.
