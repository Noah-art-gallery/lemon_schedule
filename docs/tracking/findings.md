# 현재 확인된 문제

## 카카오톡 설치 기기의 앱 전환 확인 (2026-11-07)

공식 JavaScript SDK의 throughTalk=true로 앱 우선 인증을 연결하고, Supabase state 중계·콜백 토큰 교환·PC 웹 fallback의 실제 로그인 성공을 확인했다. 현재 자동화 환경은 Windows PC이므로 카카오톡이 설치된 Android Chrome/iOS Safari에서 앱 실행→동의→원래 웹페이지 복귀를 실제로 확인하지 못했다. 이 검사는 모바일 브라우저 UA나 화면 크기 에뮬레이션으로 대체하지 않는다. 배포 후 해당 휴대폰에서 앱 전환 및 취소·미설치 웹 로그인을 확인해야 한다.

## 카카오 네이티브 로그인과 외부 연결 해제

Capacitor 외부 브라우저·딥링크 세션 복귀가 없어 네이티브에서 OAuth 시작을 명시적으로 거부하고 웹 이용을 안내한다. 네이티브 지원은 App/Browser 플러그인, 플랫폼 URL 등록, 실제 기기 callback 검증이 필요하다. 카카오 신규 가입은 서울 시간대로 시작하므로 다른 시간대 사용자는 내 정보에서 바꿔야 한다. 이메일을 요청하지 않아 기존 이메일 계정과 자동 병합되지 않는다.

카카오 외부 연결 해제 웹훅은 아직 없다. 카카오 계정 설정에서 서비스 연결을 해제하는 동작을 앱의 세션·계정 정리에 연결하려면 서버 웹훅 인증·대상 검증·세션 및 개인정보 처리 정책을 별도로 구현해야 한다. 현재 웹 로그인 성공은 이 외부 탈퇴 동기화의 검증이 아니다.

## 운영 DB 적용 완료와 원격 검사 범위 (2026-10-17)

사용자 승인 후 미적용 migration 5개를 순서대로 적용했고 원격·로컬 이력 15개가 일치한다. 차단 0개와 소유자 숨김 응원 1개의 표시 변경을 확인했으며 최신 발송 함수 ACTIVE v5를 배포했다. 기존 CLI 접근 문제는 연결된 Supabase 도구로 우회했다. 운영 DB 호환성 배포 차단은 해소됐다.

원격 보안·정책·하루 응원 pgTAP 59개를 통과했고 모두 rollback했다. 행동 검사 002는 기존 응원 전체에서 알림을 준비하는 fixture가 운영 unique key와 충돌해 전체 rollback됐다. 이 검사는 빈 DB 전용이며 운영 통과 근거로 쓰지 않는다. 003·005의 전역 fixture도 원격에서는 실행하지 않았다. 전체 검사는 격리된 로컬 DB에서 실행한다. 운영 테스트 UUID 계정은 0개다.

Security Advisor는 인증 사용자용 보안 RPC 26개, 사용자 정책 없는 서버 전용 발송 장부를 표시하며 이는 의도한 권한 계약이다. [유출 비밀번호 보호](https://supabase.com/docs/guides/auth/password-security#password-strength-and-leaked-password-protection)는 비활성 상태이며 별도 인증 운영 설정으로 남아 있다.

## 네이티브 빌드와 실제 휴대폰 알림 미검증

기존 Android 설정 파일·서버 FCM 자격·웹훅 공유 비밀·Vault 연결은 준비됐으나 이번 직접 소식 정책의 실제 알림 수신·탭 이동은 미검증이다. Android 기기 설치와 권한 허용·거부·토큰 교체를 확인해야 하며 iOS APNs·서명 자격도 필요하다. 로컬 Edge 타입 검사와 가짜 공급자 검사는 실제 전달 근거가 아니다.

강제 세션 만료 뒤 예전 계정의 서버 토큰 행이 남으면 새 계정의 같은 APNs/FCM 토큰 등록과 충돌할 수 있다. 앱은 종료·다른 계정 인증 전·등록 실패 때 OS 등록을 해제하지만 서버 행 정리까지 입증하지 못했다. 두 계정·실기기 검증 전 휴대폰 푸시는 출시 차단 상태다.

## 펫 그림 파일 누적

새 파일 업로드 뒤 경로를 바꾸므로 저장 실패가 기존 그림을 덮어쓰지 않는다. 대신 이전 버전과 메타데이터 저장에 실패한 파일은 자동 정리되지 않는다. 현재 참조 중인 경로를 보호하는 정리 작업이 없으므로 반복 저장에 따라 Storage 사용량이 증가할 수 있다.

## 화면 환경의 미확인 범위

좁은 브라우저 프레임과 CSS 글자 확대는 실제 휴대폰 키보드·안전 영역·OS 글자 확대를 대체하지 않는다. 줄인 동작 설정의 실제 미디어 전환도 아직 확인하지 못했다. 실기기 검증에서 이 환경 차이를 확인해야 한다.
