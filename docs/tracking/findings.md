# 현재 확인된 문제

## 최신 프런트엔드 운영 배포 전 DB 호환성 확인 (2026-10-17)

운영 프로젝트의 migration 이력을 읽기 전용으로 조회해 10개 적용 상태를 확인했다. 최신 `main`에 있는 `20261012120000`부터 `20261012160000`까지 5개는 미적용이다. `20261012140000_remove_blocks_and_owner_hiding.sql`은 차단 테이블·기능을 제거하고 `hidden_by_owner` 응원을 `visible`로 바꾼다. 조회 당시 차단 행은 0개, 소유자가 숨긴 응원은 1개였다. 따라서 최신 프런트엔드의 운영 배포에는 DB 호환성 작업과 숨긴 응원의 표시 변경에 대한 사용자 확인이 필요하다. 이번 UI 검수에서는 DB·Edge Function·숨김 상태를 변경하지 않았다. 기존 배포를 재배포하면 예전 소스가 다시 올라가므로 Git 커밋과 운영 배포 커밋도 함께 확인한다.

## 새 원격 기능 미적용

로컬에는 직접 소식·친구 활동 조회, 버전별 펫 경로, 차단·소유자 숨김 제거, 선택형 프로필 이모지, 하루 응원 migration 다섯 개와 갱신된 발송 함수가 있지만 원격에는 아직 적용하지 않았다. 원격 이력을 확인해 미적용 migration과 함수를 배포한 뒤 실제 계정 흐름을 확인해야 한다. 로컬 15개 migration 상태와 SQL 검사 244개는 이전 검증 기록이며 원격 적용 증거가 아니다.

2026-10-13 완료 모션 작업의 원격 적용 준비에서 `supabase migration list --project-ref jthltqvcoezawoplaxkd`는 IPv6 미지원 오류, 안내된 `supabase link --project-ref jthltqvcoezawoplaxkd`는 서버의 프로젝트 접근 권한 거부를 반환했다. 현재 CLI 계정으로는 원격 상태 확인과 일괄 적용을 진행할 수 없다. 프로젝트 접근 권한이 있는 계정으로 CLI 로그인이 필요하며 DB 변경 명령·함수 배포는 실행하지 않았다. 사용자에게 접근 가능한 CLI 로그인 요청을 전달했다.

## 네이티브 빌드와 실제 휴대폰 알림 미검증

기존 Android 설정 파일·서버 FCM 자격·웹훅 공유 비밀·Vault 연결은 준비됐으나 이번 직접 소식 정책의 실제 알림 수신·탭 이동은 미검증이다. Android 기기 설치와 권한 허용·거부·토큰 교체를 확인해야 하며 iOS APNs·서명 자격도 필요하다. 로컬 Edge 타입 검사와 가짜 공급자 검사는 실제 전달 근거가 아니다.

강제 세션 만료 뒤 예전 계정의 서버 토큰 행이 남으면 새 계정의 같은 APNs/FCM 토큰 등록과 충돌할 수 있다. 앱은 종료·다른 계정 인증 전·등록 실패 때 OS 등록을 해제하지만 서버 행 정리까지 입증하지 못했다. 두 계정·실기기 검증 전 휴대폰 푸시는 출시 차단 상태다.

## 펫 그림 파일 누적

새 파일 업로드 뒤 경로를 바꾸므로 저장 실패가 기존 그림을 덮어쓰지 않는다. 대신 이전 버전과 메타데이터 저장에 실패한 파일은 자동 정리되지 않는다. 현재 참조 중인 경로를 보호하는 정리 작업이 없으므로 반복 저장에 따라 Storage 사용량이 증가할 수 있다.

## 화면 환경의 미확인 범위

좁은 브라우저 프레임과 CSS 글자 확대는 실제 휴대폰 키보드·안전 영역·OS 글자 확대를 대체하지 않는다. 줄인 동작 설정의 실제 미디어 전환도 아직 확인하지 못했다. 실기기 검증에서 이 환경 차이를 확인해야 한다.
